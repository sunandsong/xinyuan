# 荣誉奖杯图标

放这里就自动生效，不用改代码。没放的用现有的金属奖章兜底。

- 命名：`<slug>.png`，slug 见 `lib/pages/tree_page.dart` 里 `achievements()` 每一行最后那个参数
- 规格：透明底 PNG，正方形，建议 504×504（弹窗按 168pt 显示，@3x）
- 风格：立体奖杯/奖牌，深色背景上看得清；弹窗背景是深蓝黑 `#0A0C16`
