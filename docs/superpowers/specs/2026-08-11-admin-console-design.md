# 人生清单 · 管理端设计稿

日期：2026-08-11　状态：已定稿（界面原型 v19，与用户逐页确认）
原型：https://claude.ai/code/artifact/e9bb10c3-f630-48eb-9a0c-d515bf25a7b5

## 技术选型（用户拍板）

- **前端**：React + TypeScript + antd（含 ProComponents）+ ECharts + Vite，新目录 `admin/`。
- **部署**：构建产物发布到 CloudBase 静态托管（新部署目标）；管理 API 挂在现有云函数上，需加 CORS。
- **鉴权**：环境变量 `ADMIN_KEY`（配 cloudbaserc.json），页面门禁输入一次存 localStorage，
  请求头 `X-Admin-Key` 校验；未配置 ADMIN_KEY 时管理 API 一律 403。与用户 JWT 完全隔离。
- 腾讯云 API 密钥（SecretId/SecretKey）配环境变量，供额度用量查询。

## 页面清单（侧栏结构）

1. **概览**：本月额度卡（数据库读/写、函数调用、存储，进度条 + 70%/90% 预警 + 按 7 日均速预测耗尽日）、
   导出全库备份按钮、总量卡片（用户/活跃/心愿/任务/胶囊/未处理反馈）、
   图表：新增&DAU 双线（30 天）、活跃分布、登录趋势、留存（次日/7/30 日）、功能使用量 Top、
   心愿实现 Top5、景点打卡 Top5。演示用户不计入统计。
2. **用户**：搜索/排序表格（头像、账号、昵称、性别、注册、最近登录、最近活跃、心愿完成/总数），
   行内：详情（抽屉：资料+荣誉+足迹+数据量+登录记录入口+补发荣誉/足迹+重置昵称/头像）、
   重置密码（随机 8 位回显一次）、封禁（禁登录留数据）、删号（软删）。
3. **反馈**：列表 + 未处理/已处理状态 + 处理备注 + 删除。
4. **登录日志**：时间/用户/设备/系统/App 版本/IP，按用户和时间段筛选。
5. **行为事件**：埋点明细，按事件/用户/时间筛选。
6. **数据表**（心愿/任务/时光胶囊各一页）：定制列 + 搜索 + 按用户过滤 + 「只看已完成」+
   **「看已删除（可恢复）」开关**（软删记录一键恢复）+ 新建/编辑（JSON 弹窗，保存自动刷 updatedAt）/软删。
   胶囊正文默认折叠（隐私）。
7. **内容配置**：
   - 默认清单（`preset_wishes`）：排序/标题/启用，增删改查+排序；停用不影响已拥有用户。
   - 里程碑模板（`preset_steps`）：心愿标题→步骤列表，逐步编辑弹窗，增删改查。
   - 图片素材：四张独立表（任务成绩单海报 `poster_task`、心愿清单海报 `poster_wish`、
     达成卡海报 `poster_done`、心愿头图 `hero_images`），缩略图/标语/排序/状态，
     编辑弹窗=选图上传+标语，保存即生效。
   - 荣誉定义（`achv_defs`）：固定 14 枚，仅可改名称/描述/奖杯图；判定规则只读（App 内置）；无新增。
   - 景点库（`spots`）：360+ 条，名称/省份/经纬度/被打卡数，增删改查；停用只影响新打卡匹配。
   - 屏蔽词（`blockwords`）：命中的心愿标题不进热度榜/穿透列表；违规昵称在榜单显示「用户+编号」；
     热度榜行内另有「屏蔽此标题」精确屏蔽。
   - 演示用户（users 表 `isDemo=true`）：昵称/头像/性别；完成任务数手填；
     奖杯=从 14 枚勾选（数量自动）、已完成心愿=标签（生成心愿文档喂热度榜，数量自动）、
     足迹=打卡景点标签（数量自动）。默认排除在统计与用户页之外，仅榜单参与。
   - 公告与版本：公告表（标题/内容/起止/状态，App 启动拉取展示横幅）；最低版本号（强制更新，需 App 支持）。
8. **操作日志**：管理端全部写操作审计，只增不删。
9. **门禁页**：密钥输入。

## 后端新增

  `hero_images`、`achv_defs`、`spots`、`blockwords`、`announcements`、`logins`、`events`、`admin_audit`。
- 管理 API（全部 X-Admin-Key）：stats、quota（腾讯云用量）、users CRUD+reset-password+ban、
  feedback、logins、events 查询、六内容表通用 CRUD、demo-user 专用接口、export（全库 JSON）、audit。
- 公开/用户 API 变化：`/auth/login` 记录登录日志（App 上报设备信息）+ 盖 lastLoginAt；
  `/sync/pull` 节流盖 lastActiveAt（每小时至多一次）；新增 `POST /events` 批量埋点；
  新增 `GET /config`（App 拉：默认清单、里程碑模板、海报、头图、荣誉文案、景点库、公告、最低版本）。
- 语义规则：同步集合删除=软删+刷 updatedAt；users 输出永远抹 passwordHash；
  封禁=user doc `banned=true`，登录与鉴权中间件拒绝。

## App 端配套（需发版）

1. 启动拉 `/config`，拉不到用内置资源兜底（产品配置允许静默兜底，用户数据仍不允许）；
   海报/头图从 URL 加载，预置文案/景点/荣誉文案用云端版。
2. 登录请求带设备信息（引入 device_info_plus）。
3. 埋点 `track()`：本地攒批防抖上报 `/events`，失败即丢；首批事件：页面访问、新建/完成心愿、
   新建/完成任务、景点打卡、写胶囊、分享（分类型）、一键拆步、注册、登录。
4. 公告横幅、强制更新提示、封禁提示（401 变体 `banned`）。

## 明确不做（YAGNI）
