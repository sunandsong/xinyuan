# App 端配套 Implementation Plan（计划 C / 共 3 份）

**Goal:** App 接上管理端的下发与采集通道：拉 /config（公告 + 强更版本）、登录设备上报、
行为埋点、封禁提示。做完发版。

**范围取舍：** /config 里的内容表数据（预设清单/里程碑模板/海报/景点/成就文案）本次
**不接入**——App 内置数据继续当真相。理由：全部换源要动 presets/spot_geo/share_poster/
tree_page 四处核心路径，发版风险大而收益小（内容本来就和内置一致）；等真有远程改内容
的需求再逐表接。本次只消费 announcements + minVersion。

**活跃心跳不用做：** 后端已在 /sync/pull 上按小时节流盖 lastActiveAt，App 每次打开
拉数据就是心跳。

## Tasks

### Task 1: 配置拉取 + 公告横幅 + 强更提示
- `lib/version.dart`：kAppVersion 常量（同步 pubspec 与「我的」页版本行）
- `ConfigApi.fetch()`（GET /config，登录态才拉得到）；AppData 登录后拉，
  SharedPreferences 缓存（announcements/minVersion），启动先装缓存
- 公告横幅：HomeShell 同步横幅下方，蓝色可关闭，按公告内容记「已读」不重复弹
- 强更：kAppVersion < minVersion（semver 逐段比较）→ 不可关对话框 →
  url_launcher 打开下载页 /api/releases

### Task 2: 登录设备上报 + 行为埋点 + 封禁提示
- AuthApi.login 带 device/os/appVersion（Platform.operatingSystem(+Version)，不引插件）
- `lib/analytics.dart`：内存队列，满 10 条或 App 进后台批量 POST /events，失败静默丢弃
- 埋点位：app_open、wish_add、wish_done、task_done、checkin、letter_create、
  share_create、rank_view
- 封禁：_friendly 加 'banned' 文案；401 弹窗文案透传（封禁显示「账号已被封禁」，
  不再一律说「登录已过期」）

### Task 3: 测试 + 双端模拟器验证 + 发版
- flutter test 全绿、dart analyze 干净、双端模拟器跑通
- push 触发 CI 自动打包发版
