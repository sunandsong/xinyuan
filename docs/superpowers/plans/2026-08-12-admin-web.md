# 管理端前端 Implementation Plan（计划 B / 共 3 份）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付设计稿 v19 的完整管理端网页（React + antd），部署到 CloudBase 静态托管，对接计划 A 已上线的全部管理 API。

**Architecture:** 新目录 `admin/`（Vite + React 18 + TypeScript + antd 5 + ECharts）。单一 API 客户端封装 X-Admin-Key 与 401 处理；页面按侧栏结构一页一文件；通用 CRUD 表格抽一个 hook + 组件复用于 11 张表。构建产物部署 CloudBase 静态托管。

**Tech Stack:** Vite / React 18 / TypeScript / antd 5（含 @ant-design/pro-components 可选，优先裸 antd Table 够用就不引）/ echarts + echarts-for-react。

## Global Constraints

- API BASE：`https://renshengqingdan-d8feva5q55d12bab-1258070735.ap-shanghai.app.tcloudbase.com/api`；全部管理请求带 `X-Admin-Key` 头；401 → 清 localStorage 回门禁页；403 admin_disabled → 显示"服务端未配置管理密钥"。
- 管理 API 响应格式 `{...}` 直出（错误为 `{error}`）；分页参数 skip/limit；内容表过滤参数 `f_字段=值`。
- 界面为中文；视觉即 antd 默认（蓝 #1677ff）；ECharts 双系列色 浅色 #1677ff/#fa8c16。
- 演示用户编辑是**全量回填**语义（后端非增量 patch）——表单必须回填所有字段再提交。
- announcements 的 startAt/endAt 为毫秒时间戳。
- 时光胶囊正文默认折叠，点击才展示。
- 同步表（wishes/tasks/letters）删除按钮文案「软删」；开关「看已删除（可恢复）」用 `f_deleted=true` 查询，行操作变「恢复」（upsert deleted:false）。
- 每任务结束：`cd admin && npx tsc --noEmit && npm run build` 零错误零警告（warning 可放行，error 不行）。

## 后端接口清单（Task 间共用，简报里按需引用）

门禁探活 GET /admin/ping；概览 GET /admin/stats、GET /admin/quota、GET /admin/export；
用户 GET /admin/users?q&sort&skip、GET /admin/users/:uid、POST /admin/users/:uid/reset-password|ban|delete|grant|reset-profile；
反馈 GET /admin/feedback?skip、POST /admin/feedback/:id、POST /admin/feedback/:id/delete；
日志 GET /admin/logins?uid&days&skip、GET /admin/events?event&uid&days&skip、GET /admin/audit?skip；
内容表 GET/POST /admin/content/:col、POST /admin/content/:col/delete（col ∈ 10 内容集合+3 同步集合）；
演示用户 GET/POST /admin/demo-users、POST /admin/demo-users/:uid/delete、POST /admin/demo-users/mark；
图片上传复用用户端 POST /upload 换直传凭证？——不行（用户鉴权）。**图片上传走新增管理端点**：Task 1 时先用「URL 手填」降级方案，Task 6 加后端 POST /admin/upload（复刻 upload.ts 逻辑改 admin 鉴权，属计划 A 的 1 个补丁级新增，随 Task 6 提交部署）。

### Task 1: 工程脚手架 + 门禁 + API 客户端 + 布局壳

**Files:** Create `admin/`（vite react-ts 模板）、`admin/src/api.ts`、`admin/src/Gate.tsx`、`admin/src/App.tsx`（antd Layout 侧栏结构照设计稿 v19 菜单，页面先放占位）、`admin/src/pages/` 目录。
**Interfaces (Produces):** `api.get(path)/api.post(path, body)`——自动带 key、401 清 key 抛 GateError；`useKey()` hook；菜单路由用 react-router（HashRouter，静态托管免配置回退）。
**Steps:** 脚手架（npm create vite）→ 依赖 antd/echarts/echarts-for-react/react-router-dom → Gate（密钥输入→/admin/ping 验证→localStorage）→ Layout+菜单+空页面 → build 零错误 → commit。

### Task 2: 概览页（统计+额度+导出）

**Files:** `admin/src/pages/Overview.tsx`。
**Consumes:** /admin/stats、/admin/quota、/admin/export。
**Steps:** 额度卡（4 进度条+70%/90% 预警色+7 日均速预测文案；available:false 显示"未配置腾讯云密钥"灰卡）→ 统计卡片行 → ECharts：新增&DAU 双线（stats.series）、登录趋势柱、留存/活跃分布/功能 Top/心愿 Top/景点 Top 横条 → 「导出全库备份」按钮（fetch blob 存 JSON 文件，含 truncated/errored 警示 toast）→ build → commit。

### Task 3: 用户页 + 详情抽屉 + 全部用户写操作

**Files:** `admin/src/pages/Users.tsx`。
**Consumes:** /admin/users 系列 8 个端点。
**Steps:** 搜索/排序表格（头像列：avatarUrl 有图显图无图昵称首字彩圆）→ 详情 Drawer（资料 kv、荣誉/足迹 chips+补发弹窗、看 ta 的心愿/任务/胶囊按钮=跳数据表页带 uid 参数、登录记录 10 条、重置昵称/头像）→ 重置密码 Modal（回显一次+复制按钮）→ 封禁/解封、删号（Popconfirm）→ build → commit。

### Task 4: 反馈页 + 登录日志页 + 行为事件页 + 操作日志页

**Files:** `admin/src/pages/Feedback.tsx`、`Logins.tsx`、`Events.tsx`、`Audit.tsx`。
**Steps:** 四张只读/轻写列表页（反馈含 handled 标记+备注编辑+删除；三张日志页筛选器照设计稿）→ build → commit。

### Task 5: 通用 CRUD 组件 + 三张数据表页（心愿/任务/胶囊）

**Files:** `admin/src/components/CrudTable.tsx`、`admin/src/pages/table/Wishes.tsx`、`Tasks.tsx`、`Letters.tsx`。
**Interfaces (Produces):** `<CrudTable col columns filters createDefaults jsonEditor />`——分页/过滤/新建/JSON 编辑弹窗（校验合法 JSON，保存走 upsert）/软删/看已删除+恢复。
**Steps:** CrudTable → 三页定制列（心愿：标题/用户 uid/状态/实现时间/地点/里程碑数/照片数；任务：标题/uid/日期/状态/所属心愿 id；胶囊：uid/写于/开启时间/状态/正文折叠展开）→ build → commit。

### Task 6: 后端补丁 POST /admin/upload + 内容配置六页

**Files:** Create `backend/src/handlers/admin/upload.ts`（复刻 upload.ts 换 admin 鉴权+路由注册+部署）；`admin/src/components/ImgUpload.tsx`；`admin/src/pages/content/PresetWishes.tsx`、`PresetSteps.tsx`、`Posters.tsx`（四张图表卡）、`AchvDefs.tsx`、`Spots.tsx`、`Blockwords.tsx`、`Announcements.tsx`（公告+minVersion 卡）。
**Steps:** 后端 upload 补丁（tsc+部署+curl 冒烟）→ ImgUpload（选图→凭证→PUT COS→回 URL）→ 六页：默认清单（排序上移下移=交换 sort 字段、启停）、里程碑模板（逐步输入框弹窗）、图片素材四表（缩略图+标语+排序+启停+上传弹窗）、荣誉定义（只改名/描述/图标，判定只读）、景点库（省份筛选+经纬度编辑）、屏蔽词（chips 增删）、公告（时间范围 DatePicker 写毫秒）+ 强更版本卡（读写 sys_min_version 文档）→ build → commit。

### Task 7: 演示用户页

**Files:** `admin/src/pages/DemoUsers.tsx`。
**Consumes:** /admin/demo-users 系列；成就 slug 列表从 /admin/content/achv_defs 拉。
**Steps:** 列表（计数列）→ 编辑 Modal（昵称/性别/头像 URL/任务数手填；成就 14 枚 checkbox；已完成心愿 tags 输入；打卡景点 tags；三计数自动推导显示为只读徽标）→ 全量回填语义落实 → mark 迁移按钮（输入 uid 列表一次性打标）→ build → commit。

### Task 8: 静态托管部署 + 端到端冒烟 + 收尾

**Files:** `admin/package.json` scripts 加 `deploy`（tcb hosting deploy dist -e 环境）；README 一段部署说明。
**Steps:** `tcb hosting deploy`（静态托管若未开通，脚本报错则提示用户到控制台一键开通后重跑）→ 浏览器可达 URL 记录 → 全页面手动冒烟清单（门禁→概览数字与图→用户搜索/重置密码回显→内容表增删改→演示用户建改删→导出下载）→ 收紧后端 CORS 到静态托管域名（backend http.ts 常量改+部署）→ commit + push + 合并 main。
